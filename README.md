### ✨ أبرز مميزات النظام

- **استبيان عملاء تفاعلي وفاخر:**
  - واجهة عربية سلسة ومتجاوبة 100% مع الهواتف الذكية.
  - إمكانية اختيار نوع المشروب من القائمة أو كتابة أي مشروب مخصص بحرية.
  - 10 أقسام تقييم شاملة تغطي: جودة القهوة، الحلويات، الأجواء، النظافة، طاقم الباريستا، الصوت والموسيقى، القيمة والأسعار، وسهولة الوصول والدفع.
  - قسيمة خصم فورية 10% لكل عميل بعد إرسال التقييم مع تأثيرات احتفالية.

- **توجيه تلقائي لنتائج الاستبيان لواتساب مشرف الفرع:**
  - **فرع النبلاء - الدور الثاني:** تُرسل النتيجة تلقائياً برابط واتساب مباشر لمشرف الفرع على الرقم: `00966567833138`.
  - **فرع سلطانة - الرضا مول - الدور الثاني:** تُرسل النتيجة تلقائياً برابط واتساب مباشر لمشرف الفرع على الرقم: `+966 54 873 1474`.

- **لوحة تحكم إدارية ذكية (Admin Dashboard):**
  - مؤشرات أداء فورية (CSAT, NPS, معدل الرضا الكلي).
  - رسوم بيانية تفاعلية (تطور الرضا عبر الأيام، مقارنة محاور الجودة، فترات الذروة، تصنيف NPS).
  - محرك ذكي لرصد نقاط الضعف وفرص التحسين التلقائية وتوصيات تنفيذية للإدارة.
  - سجل تفصيلي للتقييمات مع درج جانبي (Drawer) لمتابعة شكاوى وملاحظات العملاء.
  - تصدير فوري للتقارير بصيغة **Excel (.xlsx)** و **CSV** بدعم كامل للغة العربية.
  - مولد ستاندات رمز QR مخصص لطاولات الصالة والتراس جاهز للطباعة المباشرة.

- **إدارة الحساب والأمان:**
  - إمكانية تعديل البريد الإلكتروني، اسم المستخدم، وتغيير كلمة المرور المشفرة من لوحة التحكم مباشرة.
  - دعم تسجيل الدخول إما باسم المستخدم أو بالبريد الإلكتروني.

- **قاعدة بيانات سحابية متقدمة:**
  - ربط مباشر ومستمر مع **MongoDB Atlas** لحفظ الاستبيانات والتقييمات وبيانات الفروع والإدارة سحابياً بأمان وموثوقية.

### 🚀 متطلبات التشغيل

- [Node.js](https://nodejs.org/) (إصدار 18 فما فوق)
- اتصال بالإنترنت للربط مع سحابة MongoDB Atlas

---

### ⚙️ خطوات التثبيت والتشغيل المحلي

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/mshebl2/Marrakesh-Questionnaire.git
   cd Marrakesh-Questionnaire
   ```

2. **تثبيت الحزم البرمجية:**
   ```bash
   npm install
   ```

3. **إعداد متغيرات البيئة:**
   قم بنسخ ملف `.env.example` إلى ملف باسم `.env`:
   ```bash
   cp .env.example .env
   ```
   وتأكد من ملء الرابط الخاص بقاعدة بيانات MongoDB ومفتاح التشفير JWT.

4. **تشغيل الخادم:**
   ```bash
   npm start
   ```

5. **فتح المنصة في المتصفح:**
   - **صفحة الاستبيان للعملاء:** `http://localhost:3000/`
   - **بوابة تسجيل الدخول للإدارة:** `http://localhost:3000/login`
   - **لوحة تحكم الإدارة:** `http://localhost:3000/admin`
